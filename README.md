# pp-devkit-skills

AI coding assistant skills for working with Microsoft Power Platform via [pp](https://github.com/callumalpass/power-platform-devkit).

Skills for Claude Code, Codex CLI, and GitHub Copilot.

The primary skill file includes current guidance for `pp` request logging,
including JSONL storage, metadata-only defaults, result/request-body capture
settings, CLI/MCP overrides, and the PP Desktop Log tab.
